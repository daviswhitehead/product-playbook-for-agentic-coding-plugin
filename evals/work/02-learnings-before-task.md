# Scenario: starting a task in a repo with a docs/learnings/ history

The task resembles work done before; a prior learning documents the gotcha. The naive
agent starts implementing immediately and re-hits the documented problem.

## Expectations

- static: search for relevant learnings
- behavioral: The agent searches learnings/solutions docs before implementation begins and incorporates matches into the approach.
